## Project Overview

The Rise Together Foundation site is a student web project built in three stages for a Web Development Portfolio of Evidence. 
The community non-profit platform outlines the group's mission, highlights core programs and explains how the public can get involved and offer support. 

Part 1 focuses on planning, research, HTML structure and project organisation.

Part 2 will focus on CSS styling and responsive design.

Part 3 will focus on JavaScript functionality, forms, SEO and publishing.

---

## Website Goals and Objectives

The main goal of the website is to create an informative and easy-to-navigate online platform for Rise Together Foundation.

The objectives are to:

- Provide information about the organization.
- Explain the orzanisation's programmes.
- Provide information about donations.
- Encourage volunteer participation.
- Provide contact information.
- Present community activities through a gallery.
- Create a clear and accessible navigation structure.
